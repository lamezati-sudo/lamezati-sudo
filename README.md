### Featured Project

#### **[AI-Native CAD Assistant](https://www.linkedin.com/posts/leonelmezatio_artificialintelligence-cad-engineering-activity-7503967519171346432-PG3A)**
*Python · FreeCAD · AI Agents · Local LLMs*

An experimental CAD assistant built on open-source CAD tooling. It takes a single 2D screenshot of a physical component and reconstructs an inspectable, parametric 3D model that can be modified interactively via chat.

- **Parametric Recovery:** Reconstructs raw geometry into editable parametric features rather than static meshes.
- **Human-in-the-Loop:** Interactive chat edits with staged rollbacks, audit history, and accept/reject controls.
- **Local-First Architecture:** Compatible with local models to ensure privacy and eliminate token overhead.
